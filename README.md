# TradPlus Ogury Adapter Swift Package

Swift Package Manager support for the TradPlus Ogury adapter (15.13.0).

## Installation

```text
https://github.com/tradplus/TradPlusAdSDK-SPM-Ogury.git
```

```swift
.package(url: "https://github.com/tradplus/TradPlusAdSDK-SPM-Ogury.git", exact: "15.13.0")
```

Third-party dependency: Ogury SDK `5.2.3`.

## Notes

- This package automatically resolves `TradPlusAdSDK` 15.13.0.
- Add `-ObjC` to the app target's `Other Linker Flags` if required.
